# 开发模式文件范围约束

## 禁止触碰 data.js

在开发模式下，任何 `write`、`edit` 操作的目标文件**不得是 `data.js`**。

## 检查规则

写入前逐项确认：
- 目标文件不是 `data.js`（如果是 → 立即停止）
- 分支名符合 `feature/*` 或 `fix/*` 格式
- 如果是 `schema/*.json` 变更：新增字段已标记为非 required

## 越界处理

检测到即将写入 `data.js`：
→ 立即停止，回复："开发模式下禁止修改 data.js。请 /ops 切换到运营模式后操作。"
